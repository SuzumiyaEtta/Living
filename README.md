Yeah, honestly, I wasn’t really planning to write a README. If you wanna know what this mod’s about, just dive right in and play it. Even though a good README might give a better first impression, well… I have my reasons (aka I’m lazy).

But in the end, I did end up writing one—even if it’s just a little something. And for me, that’s already a pretty big project. This mod is called “Living,” but don’t get it twisted—it’s not some random life advice thing. I pretty much named it on a whim, based on a silly idea.

What this mod actually does is expand on Gods & Kings, aiming to make it as massive and polished as possible. I reworked some of the civilizations, added a bunch of totally new traits and entries you’ve never seen before, and even gave each civ alternative leaders to choose from. Oh, and I gotta mention—this mod has over 200 beliefs. Yeah, you read that right.
